# GradeVision-AI
🤖 AI system for predicting student final scores using Machine Learning and Streamlit.
# 🤖 GradeVision AI

![GradeVision AI Screenshot](screenshot.png)


## 📌 Overview

**GradeVision AI** is a Machine Learning application that predicts a student's final score based on academic information.

The project uses a trained Machine Learning model and a modern Streamlit dashboard to provide an interactive AI prediction experience.


## 🚀 Features

✨ Student final score prediction  
🤖 Machine Learning powered analysis  
📊 Interactive Streamlit dashboard  
🌌 Modern Glassmorphism AI interface  
🎓 Academic performance evaluation  
⚡ Fast prediction system  


## 🧠 Machine Learning

Algorithm:

- Random Forest Regression


The model learns from student academic data and predicts the expected final score.


## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Pickle
